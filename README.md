# cashflow.site

Open index.html in a browser. Files: index.html (site), admin.html (admin dashboard prototype), calculator.html, logo.svg / logo.png (full logo), logo-mark.svg / logo-mark.png (icon).

Prototype only: access-fee approvals, messages and admin changes are stored in the browser (localStorage) and there is no sign-in. A live version needs a backend, admin login, and a payment provider.
